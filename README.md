# CentralDocs Mobile

Aplicativo mobile da plataforma CentralDocs, desenvolvido para gerenciamento e consulta de documentos em dispositivos móveis. Desenvolvido no contexto acadêmico para prática de desenvolvimento e aplicação de padrões de arquitetura.

## Visão Geral

Este projeto foi desenvolvido como parte de atividades acadêmicas com o objetivo de criar uma interface mobile intuitiva para o ecossistema CentralDocs. O aplicativo oferece recursos para listagem, navegação e gerenciamento de arquivos, demonstrando a estruturação de software voltada para usabilidade em dispositivos móveis.

---

## Funcionalidades

* **Gestão de documentos:** consulta, listagem e navegação entre pastas e arquivos;
* **Interface responsiva:** layout otimizado para navegação intuitiva em dispositivos móveis;
* **Organização de dados:** estruturação clara de dados para consumo e exibição em tela;
* **Início de fluxo de autenticação:** preparação de interface para controle de acesso do usuário.

---

## Estrutura do Projeto

```text
CentralDocsMobile/
├── Assets/                # Recursos visuais (imagens, ícones e fontes)

├── Views/                 # Telas e páginas da aplicação
```

## Como Executar

### Pré-requisitos

* Ambiente de desenvolvimento mobile configurado;
* Gerenciador de pacotes da linguagem instalado;
* Emulador ou dispositivo físico para testes.

### Passos

1. Clone o repositório:

```bash
git clone [https://github.com/Arturqueiiroz/CentralDocsMobile.git](https://github.com/Arturqueiiroz/CentralDocsMobile.git)
cd CentralDocsMobile

```

2. Restaure as dependências:

```bash
npm install

```

3. Executar o aplicativo:

```bash
npm start

```
